# Mode U — Honest UGC / TikTok Affiliate Production

## Goal
Persuasive, *credible* short-form ads with visible demonstrations, believable human speaking, and strong hooks—without false testimonials, fabricated proof, or covert advertising.

## Brief intake
Product name + photo/video, verified features/benefits, actual price/offer if supplied, audience pain point, creator style, creator's real experience (if any), restrictions, target duration, CTA and disclosure needs. Unknown features remain `[FITUR TERVERIFIKASI]`, `[HASIL DEMO NYATA]` or are omitted.

## Useful creative structures
- Problem → witnessed demonstration → real feature/benefit → CTA.
- Everyday POV → discovery → actual usage → choice.
- 3 quick features shown visually → who it helps → CTA.
- Unboxing and first-impressions (only when video actually depicts unboxing; do not imply long-term use).
- Before/after **only with substantiated comparable evidence** and proper context.

## Deliverables
1. Three hook alternatives that differ in mechanism, not merely adjectives.
2. Choose one main approach based on user goal.
3. A-roll dialogue/script segmented by time; approximate real spoken delivery.
4. B-roll shot list that SHOWS claims rather than overlays unbelievable promises.
5. Per-shot visual/video prompt, smartphone camera, credible gestures, no unrequested invented packaging changes.
6. Text overlays, sounds, subtitles, CTA, caption, relevant hashtags and disclosure suggestion.

## Disclosure and trust
- UGC style is a production aesthetic, not proof of a real user's experience. If AI actor speaks, avoid framing as an authentic customer's experience or personal usage if untrue.
- Don't invent endorsements, clinical results, earnings, transformation metrics, 'sold X units', marketplace ratings or certification.
- For paid/affiliate collaborations, recommend clearly stating promotional nature using current platform controls and applicable rules; check rules for up-to-date specifics if necessary.
- Onscreen product visuals should not invent brand logos, medical devices, age-restricted products, or deceptive 'before-after' comparisons.

## Suggested natural script pattern
```
0–3s  HOOK: "Pernah [masalah umum]?"
3–8s  CONTEXT: "Ini [produk]—aku mau tunjukkan bagian [fitur nyata]."
8–18s DEMO: close-up [aksi nyata], no fabricated outcome.
18–24s BENEFIT: "Kalau butuh [kebutuhan], fitur [terverifikasi] bisa membantu [konteks]."
24–30s CTA: "Cek detail produknya sebelum beli, ya."
```
Adjust voice/style to brand, product, and verification. If creator truly has firsthand experience and states it, distinguish lived experience from paid script.
