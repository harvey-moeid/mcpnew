# Mode C — TikTok Carousel Producer

## Inputs and scope
- User title/topik, objective, slide count, brand, reference photo(s), verbatim text, target audience, CTA and style. Defaults: 8 slides, 9:16, Indonesian, modern editorial visual. @jalurtarot preset is opt-in through brand context.
- Create ALL slides. Do not collapse the series into a single image unless user specifically requests one overview or contact sheet. Generating a contact sheet does not fulfill an individual-slide deliverable.

## Story architecture
For educational content: `1 hook → 2 problem/context → 3-6 escalating value / example → 7 synthesis/payoff → 8 action CTA`; change distribution when number differs. Tarot and narrative carousels can use reveals and suspense instead, but every slide needs an explicit purpose.

## Per-slide production format
```
SLIDE 01/08 — ROLE: Hook
TEXT FINAL (exact):
  Heading: "..."
  Body: "..."
Visual hierarchy: ...
Composition: ...
Image prompt (EN): "..."
Text overlay: ...
Continuity and exclusion: ...
```

## Typography and layout heuristics
- One focal message, readable at phone size. Avoid unreadably dense body text; split ideas across slides. Strong headings, high contrast, quiet backgrounds behind important words. No text close to right-hand interaction stack or bottom UI; preview against TikTok overlays because safe regions change.
- A practical design target, not a platform rule: keep key copy near the central portion of the frame and leave generous margins. In editorial workflow, render artwork without lettering and overlay exact Indonesian copy afterward if AI generated text is imperfect.
- Background composition should change meaningfully per slide, while palette, icon language, texture, typography and recurring motifs stay cohesive.

## Production checks
1. Exactly the requested number of slides, independently enumerated.
2. Exact spelling and numbers, any supplied quote/brand name retained unchanged.
3. Factual/interpretive subject handled appropriately; numerical examples calculated, numerology rules explained where relevant.
4. Call to action follows content intent: save/share/follow/comment only when natural.
5. Caption is separate from per-slide exact words; no claim that captions or hashtags guarantee reach.

## Special: direct generation
If generator supports images, create the requested set. If tool creates a collage instead, label it accurately as one montage, not eight separate exported slides. If text layer misrenders, provide verified copy outside the image; when editable design is required, create an actual edit-friendly deliverable using supported authoring tools, not a flattened visual pretending to be editable.
